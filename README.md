# Calculadora Básica en Java

Solo se compilará con números con decimales permitidos

Suma: Suma dos números
Resta: Resta el segundo número al primero
Multiplicar: Multiplica dos números
Dividir: Divide el primer número entre el segundo
Potencia: Multiplica el primer número la cantidad que indique el segundo
Modulo: Divide el primer número entre el segundo y se queda con el resto

Estos son los ejemplos usando 20 de primer parámetro y 5 de segundo
Suma: 25.0
Resta: 15.0
Multiplicación: 100.0
División: 4.0
Potencia: 3200000.0
Modulo: 0.0
